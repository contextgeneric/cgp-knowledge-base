# CGP v0.2.0

The pre-launch cleanup, published eleven days before CGP was announced publicly. It renames the
central macro to `#[cgp_component]` and lands the type-level vocabulary — `Cons`/`Nil`,
`Either`/`Void`, `Field`, `Product!`, `Sum!` — essentially in the form it still has.

- **Tag** — [`v0.2.0`](https://github.com/contextgeneric/cgp/releases/tag/v0.2.0), 8 December 2024
- **Announcement** — none of its own, but it is the version the
  [launch post](../website/blog/early-preview-announcement.md) of 19 December 2024 describes.
- **Changelog** — the [oldest entry](https://github.com/contextgeneric/cgp/blob/main/CHANGELOG.md),
  dated 2025-12-08 in the file; the tag says 2024-12-08 and the tag is right.
- **Relation to today** — the type-level primitives are current; the component macro's syntax has
  moved on and the preset it introduced is gone.

## What it introduced

The **type-level vocabulary** is the durable contribution. This release introduces `Cons` and `Nil`
for products, `Either` and `Void` for sums, `Field` for a value paired with its name tag, and the
`Product!`, `product!`, and `Sum!` macros that build them. It also changes `symbol!` to expand into a
`Cons`/`Nil` list of `Char`, which is the representation
[`Symbol!`](../cgp/reference/macros/symbol.md) still uses. Everything the base documents as
[type-level primitives](../cgp/reference/types/cons.md) dates from here.

Three provider patterns arrive with the new `cgp-type` crate: **`HasType`**, CGP's built-in
abstract-type component; **`UseContext`**, for satisfying a provider trait through the context's own
consumer impl; and **`WithProvider`**, the adapter that lets a foundational provider stand in as a
named component's provider. `FieldGetter` is added as the provider-side face of `HasField`, and
`HasFieldMut` is derived alongside `HasField`. `DelegateTo` is introduced as a generalized delegation
provider and renamed `UseDelegate` within the same release; `UseDelegatedType` accompanies it.

Two renames make the surface recognizable. `#[derive_component]` becomes **`#[cgp_component]`** and
switches from positional arguments to a named form,
`#[cgp_component { name: ..., context: ..., provider: ... }]` — the changelog supplies a regex for
migrating. `define_components!` becomes **`cgp_preset!`**, gaining the `replace_with!` and
`for_each_replace!` helpers and the `IsPreset` trait for bulk delegation.

Finally, `cgp-async` gains feature flags — `async`, `send`, `sync`, `static`, `full` — with
`MaybeSend`, `MaybeSync`, and `MaybeStatic` aliases, so that async can be compiled away entirely and
`#[async_trait]` desugars to a sync function when disabled.

## What it changed or removed

`HasField::Field` is renamed **`HasField::Value`**, which is the name it still carries. The `Sized`
constraint is dropped from `Async` so it can be used inside `dyn` traits. `DelegateErrorComponents` in
`cgp-error` is replaced by the general `DelegateTo`, and `cgp-error-std` moves from
`std::error::Error` to `core::error::Error`.

## How it relates to v0.8.0

This release splits cleanly into what survived intact and what was later swept away.

**Still current, essentially unchanged.** The product and sum lists
([`Cons`/`Nil`](../cgp/reference/types/cons.md), [`Either`/`Void`](../cgp/reference/types/either.md)),
[`Field`](../cgp/reference/types/field.md), [`Product!`](../cgp/reference/macros/product.md) and
[`Sum!`](../cgp/reference/macros/sum.md), [`HasType`](../cgp/reference/components/has_type.md),
[`UseContext`](../cgp/reference/providers/use_context.md),
[`WithProvider`](../cgp/reference/providers/with_provider.md),
[`UseDelegatedType`](../cgp/reference/providers/use_delegated_type.md),
[`HasFieldMut` and `FieldGetter`](../cgp/reference/traits/has_field.md), and `HasField::Value` all
date from here and are documented in the reference as current.

**Renamed since.** `symbol!` became [`Symbol!`](../cgp/reference/macros/symbol.md) and `Char` became
[`Chars`](../cgp/reference/types/chars.md), both in [v0.5.0](v0-5-0.md). `DelegateTo` was already
`UseDelegate` by the end of this release.

**Removed since.** `cgp_preset!` and `IsPreset` were removed in [v0.8.0](v0-8-0.md), superseded by
[namespaces](../cgp/concepts/namespaces.md). The `Async` trait and its `MaybeSend`/`MaybeSync`/
`MaybeStatic` aliases, and with them the async feature flags this release built, were removed in
[v0.5.0](v0-5-0.md) — the `Send` guarantee is now recovered at the point of use through the
[proxy-trait pattern](../cgp/concepts/send-bounds.md) rather than imposed globally.

**Superseded in practice.** [`UseDelegate`](../cgp/reference/providers/use_delegate.md) still exists
and CGP's own error and handler components are still defined with it, but for new code the `open`
statement of [`delegate_components!`](../cgp/reference/macros/delegate_components.md) replaced it in
[v0.8.0](v0-8-0.md); see [dispatching-per-type](../cgp/guides/dispatching-per-type.md). The
`#[cgp_component { ... }]` brace syntax still parses, but the positional
`#[cgp_component(Greeter)]` form added in [v0.4.0](v0-4-0.md) is what current code writes.
