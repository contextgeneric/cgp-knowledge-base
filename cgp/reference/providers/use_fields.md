# `UseFields`

`UseFields` is a zero-sized provider that implements a getter component by reading each getter method's value from the context field named after the method.

## Purpose

`UseFields` is the provider form of the convention that the method `name` reads the field `name`. Wiring a [`#[cgp_getter]`](../macros/cgp_getter.md) component to `UseFields` makes every method read the field whose name equals the method's, through [`HasField`](../traits/has_field.md) keyed by a [`Symbol!`](../macros/symbol.md).

It brings the [`#[cgp_auto_getter]`](../macros/cgp_auto_getter.md) convention into a wired component. `#[cgp_auto_getter]` emits a blanket impl that applies to every context with matching fields, with nothing to wire. `UseFields` gives a `#[cgp_getter]` component the same behavior as one wiring choice among others.

The name marks the difference from [`UseField<Tag>`](use_field.md). `UseField` reads a field the wiring names, so a method can read a field of any name, and it exists only for single-method getters. `UseFields` takes no parameter, keys every method on its own name, and works for any number of methods.

## Definition

`UseFields` is a unit struct defined in `cgp-component` and exported by the prelude:

```rust
pub struct UseFields;
```

The impl that gives it meaning is generated by `#[cgp_getter]`.

## Behavior

`#[cgp_getter]` generates a `UseFields` impl of the getter's provider trait, with one `HasField` bound and one method body per getter method. For this getter:

```rust
#[cgp_getter]
pub trait HasFoo {
    fn foo(&self) -> &str;
}
```

the impl is:

```rust
impl<__Context__> FooGetter<__Context__> for UseFields
where
    __Context__: HasField<Symbol!("foo"), Value = String>,
{
    fn foo(__context__: &__Context__) -> &str {
        __context__.get_field(PhantomData::<Symbol!("foo")>).as_str()
    }
}
```

The getter macros' return-type conversions apply, so a `&str` return reads a `String` field and appends `.as_str()`. The impl is paired with an `IsProviderFor` impl carrying the same bounds, so the [check traits](../../concepts/check-traits.md) report a missing field by name.

`UseFields` is one of the three providers `#[cgp_getter]` generates impls for. The others, [`UseField`](use_field.md) for a wiring-chosen field and [`WithProvider`](with_provider.md) for a foundational field getter, exist only for single-method getters.

## Examples

This getter has two methods, each read from its same-named field:

```rust
use cgp::prelude::*;

#[cgp_getter]
pub trait HasFooBar {
    fn foo(&self) -> &str;
    fn bar(&self) -> &u8;
}

#[derive(HasField)]
pub struct App {
    pub foo: String,
    pub bar: u8,
}

delegate_components! {
    App {
        FooBarGetterComponent: UseFields,
    }
}

check_components! {
    App {
        FooBarGetterComponent,
    }
}
```

`app.foo()` reads the `foo` field and `app.bar()` reads `bar`. If a value lived under another name, the getter would need its own single-method component wired to `UseField<Symbol!("…")>`.

## Related constructs

These constructs are the ones `UseFields` works with:

- [`#[cgp_getter]`](../macros/cgp_getter.md) — generates its impl.
- [`#[cgp_auto_getter]`](../macros/cgp_auto_getter.md) — the unwired blanket form of the same convention.
- [`UseField`](use_field.md) and [`WithProvider`](with_provider.md) — the other two getter providers.
- [`HasField`](../traits/has_field.md), [`Symbol!`](../macros/symbol.md), and [`#[derive(HasField)]`](../derives/derive_has_field.md) — the field access it relies on.
